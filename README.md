# ComposerM

PWA para planejamento de materiais, quantitativos por estaqueamento e apoio à engenharia rodoviária.

## Instalação no Android

Abra a versão publicada no Chrome e use **Instalar ComposerM**. Após a instalação, o app abre em modo standalone, sem a barra de endereço do navegador.

## Offline

Após a primeira carga, o service worker mantém o núcleo da aplicação disponível offline.

## Interface

A interface bloqueia seleção acidental de textos durante o uso, mantendo seleção normal apenas em campos editáveis.
